  1. Initial Launch & Business Mode: Open Invify on your tablet, POS terminal, or PC. Choose your business operating model (Retail, School, or Services).

  4. Security & PIN Setup: Change the default Manager PIN, create Cashier/Staff accounts, and configure the Emergency Lock Screen passcode.
  5. Hardware Pairing: Connect your Bluetooth/USB thermal receipt printer and card reader in Printer & MPOS.
  6. License Activation: Enter your Pro activation key or sync your device with the Cloud Admin Portal.

1. System Architecture & Offline-First Engine

Invify is engineered to guarantee 100% uptime, even during internet outages, network blackouts, or server maintenance.

💾 Offline-First Idempotent Ledger

Every transaction, invoice, result score, or payment is recorded locally into an encrypted, immutable database before any network call. Transactions are never dropped or double-counted.

📡 Local Area Network (LAN) Peer Sync

Multiple cashier terminals, bursary tablets, or sales counters synchronize in real-time over a local Wi-Fi router without requiring an active internet connection.

☁️ Real-Time Cloud Replication

When internet is available, transactions automatically mirror to the Invify Cloud Platform for multi-branch monitoring, automated bank reconciliation, and remote web access.

🛡️ Enterprise Security & Audit Trail

All administrative adjustments, price changes, refunds, and permission elevations are permanently recorded in the system audit log with operator timestamps.

4. Security, Staff Roles & Emergency Lock

Multi-tiered role-based access control (RBAC) ensures strict separation of duties and eliminates unauthorized ledger modifications.

🛡️ User Role Hierarchy

  • Super Admin / Proprietor: Full system control, Quaser payment keys, database restore, license management.
  • Manager / Admin: Price overrides, discount authorization, stock valuation, inventory restock, refunds.
  • Finance / Bursar: Fee collections, bank reconciliation, debt ledgers, payment matching.
  • Cashier / Teacher: Standard POS checkout, student result entry, lesson notes (no financial settings access).

🚨 Emergency Lock Screen

In case of emergency, physical security threats, or unauthorized terminal tampering, activating the Emergency Lock immediately freezes all screens behind a secure master passcode. No sales, refunds, or customer data can be accessed until unlocked.

6. Printers, MPOS & Peripheral Setup

Invify is compatible with industry-standard POS hardware, barcode scanners, and peripheral accessories.

🖨️ Thermal Receipt Printers

Supports 58mm (compact) and 80mm (standard) ESC/POS printers over Bluetooth, USB OTG, or LAN Network (TCP/IP). Built-in thermal printers on Android POS devices (Sunmi, POSIFLEX, Telpo) are natively supported with instant paper cutting.

💳 MPOS Card Readers & Scanners

Pair wireless MPOS debit card terminals for in-person card payments. USB and Bluetooth laser/2D barcode scanners require zero configuration—simply scan any product barcode to instantly add it to the cart.

7. Multi-Till Peer-to-Peer LAN Synchronization

Scale your store or school across multiple checkouts and offices without relying on cloud internet:

🔗 How to Set Up Multi-Device LAN Sync (No Internet Needed)
  1. Connect all terminals (tablets, phones, PCs) to the same local Wi-Fi router or mobile hotspot.
  2. Designate the main terminal as the Sync Master (in Settings → Device Sync).
  3. On other cashier/teacher terminals, tap Join Master. The devices will discover each other automatically via local mDNS/IP broadcast.
  4. All sales, student bills, stock deductions, and payments will now sync across all screens in real-time.

10. Database Backup, Snapshot & Disaster Recovery

Protect your institutional data against hardware loss, device theft, or physical damage.

💾

OFFLINE DATABASE SNAPSHOTS & CLOUD BACKUPS

Maintain complete data independence with portable encrypted backups.

  • Creating a Local Backup: Go to Settings → Database → Export Backup. Save the encrypted JSON file to an SD card, USB drive, or secure email.
  • Restoring to a New Device: Install Invify on the new terminal, go to Settings → Database → Restore Snapshot, and select your backup file. All products, sales history, student profiles, and ledgers restore in seconds.
  • Automated Cloud Backups: For Pro/Standard connected devices, daily encrypted snapshots are automatically preserved in the Invify Cloud.

11. Standard Operating Procedures (SOPs)

Recommended operational workflows for peak efficiency and error prevention.

☀️ Daily Cashier / Operator Workflow
  1. Log in using your assigned Staff PIN.
  2. Verify that the receipt printer status is active (Green dot on tile).
  3. Count and confirm your opening cash drawer float.
  4. Issue receipts for every transaction; record exact payment methods.
  5. At shift end, print the Transaction History summary and balance physical cash against recorded totals.
📅 Weekly Manager Maintenance Routine
  1. Audit the Low Stock and Defaulter lists.
  2. Review the Reconciliation Hub to resolve any unallocated transfers.
  3. Perform an offline Database Backup and save to external storage.
  4. Inspect the Audit Logs for unauthorized voids or overrides.

12. Master Troubleshooting Matrix & FAQ

Symptom Underlying Cause Recommended Solution
Printer not printing / Red dot Bluetooth unpaired, thermal paper roll inserted backwards, or printer sleep mode. Ensure paper feeds from under the roll, power cycle printer, open Printer & MPOS and tap Connect. Run a Test Print.
Cloud Icon shows Red (Offline) No internet connection or online sync disabled. Normal behavior—Invify continues 100% offline. Invoices queue in the outbox and sync automatically once internet returns.
LAN Sync not finding other tills Devices connected to different Wi-Fi networks or router client isolation is ON. Ensure all devices are on the exact same Wi-Fi SSID/band. Disable "AP Isolation" on the router or use a mobile hotspot.
Forgotten Manager PIN Security lockout after multiple incorrect attempts. Use your Super Admin Recovery Passcode or reset the PIN via the Admin Web Cloud Dashboard.
Unmatched Bank Deposit Customer paid via transfer without specifying reference code. Open Reconciliation → Locate payment in Unmatched Queue → Tap Assign to Customer / Student.
