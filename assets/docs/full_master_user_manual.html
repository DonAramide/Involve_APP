Getting Started, System Settings, Core Features & Admin Web Cloud Dashboard

Welcome to the Invify General User Manual. Invify is a next-generation enterprise business management suite built with an offline-first architecture, hardened idempotent financial ledger, local peer-to-peer (LAN) synchronization, and seamless cloud replication.   5. Hardware Pairing: Connect your Bluetooth/USB thermal receipt printer and card reader in Printer & MPOS.
  6. License Activation: Enter your Pro activation key or sync your device with the Cloud Admin Portal.

1. System Architecture & Offline-First Engine

Invify is engineered to guarantee 100% uptime, even during internet outages, network blackouts, or server maintenance.

💾 Offline-First Idempotent Ledger

Every transaction, invoice, result score, or payment is recorded locally into an encrypted, immutable database before any network call. Transactions are never dropped or double-counted.

📡 Local Area Network (LAN) Peer Sync

Multiple cashier terminals, bursary tablets, or sales counters synchronize in real-time over a local Wi-Fi router without requiring an active internet connection.

☁️ Real-Time Cloud Replication

When internet is available, transactions automatically mirror to the Invify Cloud Platform for multi-branch monitoring, automated bank reconciliation, and remote web access.

🛡️ Enterprise Security & Audit Trail

All administrative adjustments, price changes, refunds, and permission elevations are permanently recorded in the system audit log with operator timestamps.

4. Security, Staff Roles & Emergency Lock

Multi-tiered role-based access control (RBAC) ensures strict separation of duties and eliminates unauthorized ledger modifications.

🛡️ User Role Hierarchy

  • Super Admin / Proprietor: Full system control, Quaser payment keys, database restore, license management.
  • Manager / Admin: Price overrides, discount authorization, stock valuation, inventory restock, refunds.
  • Finance / Bursar: Fee collections, bank reconciliation, debt ledgers, payment matching.
  • Cashier / Teacher: Standard POS checkout, student result entry, lesson notes (no financial settings access).

🚨 Emergency Lock Screen

In case of emergency, physical security threats, or unauthorized terminal tampering, activating the Emergency Lock immediately freezes all screens behind a secure master passcode. No sales, refunds, or customer data can be accessed until unlocked.

7. Multi-Till Peer-to-Peer LAN Synchronization

Scale your store or school across multiple checkouts and offices without relying on cloud internet:

🔗 How to Set Up Multi-Device LAN Sync (No Internet Needed)
  1. Connect all terminals (tablets, phones, PCs) to the same local Wi-Fi router or mobile hotspot.
  2. Designate the main terminal as the Sync Master (in Settings → Device Sync).
  3. On other cashier/teacher terminals, tap Join Master. The devices will discover each other automatically via local mDNS/IP broadcast.
  4. All sales, student bills, stock deductions, and payments will now sync across all screens in real-time.

10. Database Backup, Snapshot & Disaster Recovery

Protect your institutional data against hardware loss, device theft, or physical damage.

💾

OFFLINE DATABASE SNAPSHOTS & CLOUD BACKUPS

Maintain complete data independence with portable encrypted backups.

  • Creating a Local Backup: Go to Settings → Database → Export Backup. Save the encrypted JSON file to an SD card, USB drive, or secure email.
  • Restoring to a New Device: Install Invify on the new terminal, go to Settings → Database → Restore Snapshot, and select your backup file. All products, sales history, student profiles, and ledgers restore in seconds.
  • Automated Cloud Backups: For Pro/Standard connected devices, daily encrypted snapshots are automatically preserved in the Invify Cloud.

12. Master Troubleshooting Matrix & FAQ

Symptom Underlying Cause Recommended Solution
Printer not printing / Red dot Bluetooth unpaired, thermal paper roll inserted backwards, or printer sleep mode. Ensure paper feeds from under the roll, power cycle printer, open Printer & MPOS and tap Connect. Run a Test Print.
Cloud Icon shows Red (Offline) No internet connection or online sync disabled. Normal behavior—Invify continues 100% offline. Invoices queue in the outbox and sync automatically once internet returns.
LAN Sync not finding other tills Devices connected to different Wi-Fi networks or router client isolation is ON. Ensure all devices are on the exact same Wi-Fi SSID/band. Disable "AP Isolation" on the router or use a mobile hotspot.
Forgotten Manager PIN Security lockout after multiple incorrect attempts. Use your Super Admin Recovery Passcode or reset the PIN via the Admin Web Cloud Dashboard.
Unmatched Bank Deposit Customer paid via transfer without specifying reference code. Open Reconciliation → Locate payment in Unmatched Queue → Tap Assign to Customer / Student.

3. New Term Bill & Billing Records

The school's front-desk billing and collection engine operates with offline-first speed and hardened ledger integrity.

🧾

NEW TERM BILL (Student Point of Sale)

Issue immediate invoices and record fee payments for enrolled students.

  • Student Lookup: Type student name or admission number. The system instantly loads their class and previous debt balance.
  • Item Selection: Select required fee items (Tuition, Books, Uniform, Bus). Quantities and custom discounts can be applied.
  • Carry-Forward Balance: Any unpaid balance from previous terms is automatically appended to the current bill summary.
  • Multi-Channel Payment: Record payments via Cash, Bank Transfer, POS Card Reader, Cheque, or Split Payment.
  • Instant Receipting: Automatically triggers 58mm/80mm thermal receipt printing or generates a detailed A4 PDF receipt.
📊

BILLING RECORDS (Invoice & Receipt Archive)

Complete historical registry of every bill issued by the bursary department.

  • Multi-Filter Search: Filter invoices by Term, Class, Payment Status (Paid, Partial, Unpaid), or Cashier.
  • Reprint & Share: Reprint receipts at any time or share digital PDF receipts directly with parents via WhatsApp or Email.
  • Audited Reversals: Authorize refunds or bill adjustments with compulsory audit remark logging to prevent bursary fraud.
💡 PRO TIP: Idempotent Ledger Protection Invify uses an immutable, idempotent ledger. Even during network drops or power outages, transactions are recorded locally without risk of double-billing or dropped payments.

3. New Invoice & Point of Sale (POS)

The core billing engine designed for high-volume counter sales with offline-first reliability.

🛒

NEW INVOICE (Checkout Counter)

Rapid item scanning, cart adjustments, and flexible multi-channel payment collection.

  • Barcode Scanning & Quick Search: Use USB/Bluetooth laser scanners, device camera, or text search to add items in milliseconds.
  • Cart Adjustments: Adjust quantities, apply item-level or invoice-level discounts, and toggle tax/VAT.
  • Customer Assignment: Attach sales to registered customers to track purchases or record credit/debt sales.
  • Multi-Channel Payment: Accept Cash, POS Card, Bank Transfer, Store Credit, or Split Payment (e.g. 50% Cash + 50% Transfer).
  • Instant Receipt Printing: Auto-triggers 58mm/80mm thermal slips or generates digital A4 PDF receipts.
⚡ 4-Step Cashier Checkout Procedure
  1. Tap NEW INVOICE from the dashboard or press shortcut key.
  2. Scan products or search and tap items to add to the cart.
  3. Tap Charge / Pay, select the payment method, and enter amount tendered.
  4. Collect payment, hand customer the printed receipt and change. The stock is automatically deducted in real time.

12. Troubleshooting & Frequently Asked Questions

Issue Observed Probable Cause Recommended Action
Printer dot is Red / Not printing Bluetooth disconnected, out of paper, or cover open. Check paper roll, power cycle printer, open Printer & MPOS, and tap Connect. Run a Test Print.
Barcode scanner not finding item Barcode not registered or scanned with extra prefix. Open Stock, edit the product, tap the barcode field, and rescan the product barcode to map it correctly.
Negative or wrong stock count Items sold before entering supplier restock invoice. Open Stock, search the item, and tap Restock / Stock In to update quantity to actual physical count.
Cloud icon shows Red (Offline) Internet connection down or online sync disabled. Sales continue uninterrupted offline. When internet is restored, the system automatically syncs pending invoices to the cloud.
Access Denied to Finance Analytics Staff account lacks Manager/Admin privileges. Authenticate using an Admin or Finance staff PIN to unlock financial dashboards.

3. New Job

Use NEW JOB (home tile or dashboard FAB) to open a work order. Jobs save offline first (“Save Job Offline”) and sync when the cloud is available.

Create a job — step by step
  1. Customer: Select an existing client or register a new one (name + phone).
  2. Project photo (optional): Take a photo or pick from gallery for “before / expected” reference.
  3. Job type / title: Type freely or pick from presets (e.g. Oil Change, Traditional Dress Sewing).
  4. Description: Notes, measurements, fabric/parts info.
  5. Pricing:
    • Simple: enter one Total Cost.
    • Detailed Billing: toggle on to split Workmanship / Labor and Materials / Parts.
  6. Due date: Optional completion / pickup date.
  7. Warranty: If enabled in Settings, choose duration (1 Month … 3 Years).
  8. Tap Save Job Offline.
Workmanship vs materials Detailed billing keeps professional fees separate from parts. Labor presets and material prices come from Services Setup — configure them once so staff can quote faster.

9. Job Status Lifecycle

Status Meaning Typical next step
PENDING Job booked / quote accepted; work not started. Assign technician; move to In Progress when work begins.
IN_PROGRESS Actively being worked. Update materials/payments as needed; mark Ready when done.
READY Finished and waiting for customer pickup or delivery. Collect remaining balance; print/share receipt; mark Delivered.
DELIVERED Job closed and handed over. Keep PDF/receipt for records; review analytics.

10. Quick Tips

Offline-first

Jobs and payments save locally. Watch the top-bar cloud icon; when it shows healthy, data will sync.

Pull to refresh

On Services Overview, pull down after taking payments or changing statuses on another device.

Printer first

If Print Receipt fails, open Printer & mPOS and confirm the printer is paired before retrying from Job Details.

Ready = notify customer
